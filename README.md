# 💙 Сайт-приглашение — Инструкция по настройке и деплою

## 📁 Структура файлов

```
приглашение/
├── index.html      ← основной файл сайта
├── style.css       ← стили
├── script.js       ← логика
├── bg.jpg          ← ТЫ ДОБАВЛЯЕШЬ: фоновое фото
├── photo.jpg       ← ТЫ ДОБАВЛЯЕШЬ: центральное фото на 1-м экране
└── README.md       ← эта инструкция
```

---

## 🖼️ Шаг 1: Добавь фотографии

Положи рядом с `index.html` два файла:

- **`photo.jpg`** — фото, которое будет в центре на первом экране (желательно квадратное, минимум 400×400)
- **`bg.jpg`** — фото для размытого фона (любой размер, лучше горизонтальное)

> **Важно:** имена файлов должны быть именно `photo.jpg` и `bg.jpg` (маленькими буквами).

## 📧 Шаг 2: Настрой EmailJS (получать ответы на почту)

### 2.1 Регистрация
1. Зайди на [https://www.emailjs.com](https://www.emailjs.com) и создай бесплатный аккаунт

### 2.2 Добавь Email Service
1. Перейди в **Email Services** → **Add New Service**
2. Выбери **Gmail** (или другой)
3. Нажми **Connect Account** и подключи свою почту
4. Запомни **Service ID** (например: `service_abc123`)

### 2.3 Создай Email Template
1. Перейди в **Email Templates** → **Create New Template**
2. В поле **Subject** напиши: `💙 Ответ на приглашение!`
3. В поле **Body (HTML)** вставь:

```html
<h2>💙 Пришёл ответ на свидание!</h2>
<p><b>Дата:</b> {{date}}</p>
<p><b>Место:</b> {{location}}</p>
<p><b>Программа:</b> {{program}}</p>
<p><b>Напиток:</b> {{drink}}</p>
<p><b>Формат:</b> {{format}}</p>
<p><b>Фото-настроение:</b> {{has_photo}}</p>
<p><b>Время ответа:</b> {{timestamp}}</p>
```

4. Нажми **Save** и запомни **Template ID** (например: `template_xyz456`)

### 2.4 Получи Public Key
1. Перейди в **Account** → вкладка **General**
2. Скопируй **Public Key** (например: `abcDEFghiJKL123`)

### 2.5 Вставь ключи в script.js

Открой `script.js` и замени значения в блоке `CONFIG` (строки 9-11):

```js
const CONFIG = {
  emailjs: {
    publicKey:  'abcDEFghiJKL123',   // ← твой Public Key
    serviceId:  'service_abc123',     // ← твой Service ID
    templateId: 'template_xyz456',   // ← твой Template ID
  },
```

## 🚀 Шаг 4: Выложи на GitHub Pages

### 4.1 Создай репозиторий
1. Зайди на [https://github.com](https://github.com) (нужен аккаунт)
2. Нажми **+** → **New repository**
3. Назови, например: `invitation` или `date`
4. Выбери **Public**
5. Нажми **Create repository**

### 4.2 Загрузи файлы
1. На странице репозитория нажми **uploading an existing file** (или **Add file** → **Upload files**)
2. Перетащи все файлы: `index.html`, `style.css`, `script.js`, `bg.jpg`, `photo.jpg`
3. Нажми **Commit changes**

### 4.3 Включи GitHub Pages
1. Зайди в **Settings** репозитория → **Pages** (в левом меню)
2. В секции **Source** выбери **Deploy from a branch**
3. Ветка: **main** / папка: **/ (root)**
4. Нажми **Save**

### 4.4 Получи ссылку
Через 1-2 минуты сайт будет доступен по адресу:
```
https://ТВОй-НИК.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/
```

Эту ссылку отправь другу! 🎉

## ❓ Часто задаваемые вопросы

**Q: Фото не отображается?**  
A: Убедись, что файл называется точно `photo.jpg` (маленькими буквами) и лежит в той же папке, что и `index.html`

**Q: Письмо не приходит?**  
A: Проверь, что вставил все три ID в `script.js`. Бесплатный план EmailJS — 200 писем в месяц.

**Q: Можно использовать PNG вместо JPG?**  
A: Да, просто измени `photo.jpg` → `photo.png` в `index.html` (строка с `src="photo.jpg"`) и `bg.jpg` → `bg.png` (в `style.css`, строка `url('bg.jpg')`)
